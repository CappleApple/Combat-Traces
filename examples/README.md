# Optional pack examples

- `combattraces-example-datapack.zip`: install in a world's `datapacks/` folder and run `/reload`. Diamond swords receive a double-ended visual emitter, fire/lightning elements, and a brighter base style. Anvils receive extra sparks. Gameplay is unchanged.
- `combattraces-example-resourcepack.zip`: install in `resourcepacks/` and enable it. It replaces the slash PNG with the bundled orange flame tile to demonstrate texture replacement.

The unpacked source directories are provided alongside the ZIPs. These examples are not enabled by the mod itself.
